#### 一、 项目介绍
(协同过滤推荐算法+AI智能助手)基于SpringBoot的大学生实习就业管理系统

一、前台：大学生角色
可使用的功能包括：
基础入口：系统首页
就业相关：实习岗位查看、就业资料查询、就业资讯浏览
社交互动：社区交流
智能辅助：智能 AI（求职 / 实习咨询工具）
个人中心：包含修改密码、聊天记录、个人简历管理、实习申请、面试安排 / 结果、反馈建议、个人发布内容、收藏内容等功能
二、后台：管理员角色
负责系统全局管理，功能包括：
基础入口：系统首页
人员管理：大学生信息管理
内容管理：社区交流内容管理、企业信息管理
岗位管理：岗位类型配置、实习岗位发布管理
流程管理：个人简历审核、就业资料管理、实习申请 / 面试安排 / 面试结果的审核、反馈建议处理
三、后台：企业角色
面向招聘方的功能包括：
基础入口：系统首页
招聘管理：实习岗位发布、就业资料管理
流程管理：实习申请处理、面试安排 / 面试结果管理
个人中心：企业自身信息管理
#### 二、项目技术
后端： SpringBoot+Mybatis-Plus

前端：Vue + Vue Router + ELementUI + Axios

#### 三、 运行环境
开发语言：Java

项目架构：B/S架构

开发工具：IDEA，Eclipse,Myeclipse都可以。推荐IDEA

JDK版本：1.8

数据库版本: MySQL8.0.x/MySQL5.7.x

项目管理：Maven

Node版本：14

#### 五、安装教程
使用Navicat或者其它工具，在mysql中创建对应名称的数据库，并导入项目的sql文件；

使用IDEA/Eclipse导入项目，若为maven项目请选择maven;导入成功后请执行maven clean;maven install命令，然后运行；

进入src/main/resources修改application.yml里面的数据库配置

启动项目
